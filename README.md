# Понятно про — сайт-источник для Дзена

Готовый контент-проект по схеме «вариант B»: статьи публикуются на своём сайте, Дзен забирает их из RSS и показывает в канале. Параллельно сайт можно монетизировать через РСЯ.

## Что внутри

```
dzen-portal/
├── build.py                 генератор сайта + RSS 2.0 под требования Дзена
├── site.config.json         настройки: домен, рубрики, лента, реклама, Метрика
├── CONTENT.md               правила публикаций и банк из 60 тем
├── SETUP.md                 пошагово: домен → хостинг → Вебмастер → РСЯ → Дзен → Telegram
├── content/                 14 готовых статей в 4 рубриках
│   ├── rabota-i-dohod/      Работа и доход
│   ├── ii-instrumenty/      ИИ и инструменты
│   ├── dom-i-byt/           Дом и быт
│   └── karta-i-put/         Авто и путь
├── static/
│   ├── style.css            оформление сайта
│   ├── covers/              обложки 1200×630 (JPEG)
│   └── root/                файлы подтверждения прав (Вебмастер, Дзен)
├── scripts/
│   ├── make_cover.py        генерация обложек по заголовку
│   ├── validate.py          проверка ленты по требованиям Дзена
│   └── tg_report.py         отчёт в Telegram
├── ads/                     сюда кладётся код РСЯ
├── .github/workflows/       автодеплой на GitHub Pages
└── public/                  результат сборки (в git не нужен)
```

## Быстрый старт

```bash
# 1. собрать сайт
python build.py --clean

# 2. проверить, что лента соответствует требованиям Дзена
python scripts/validate.py

# 3. посмотреть результат локально
python -m http.server 8000 -d public
#    затем откройте http://127.0.0.1:8000/
```

`base_url` в конфиге можно указывать и с подкаталогом (`https://login.github.io/repo`) — генератор сам подставит префикс в ссылки, sitemap, robots и RSS. Это позволяет запуститься на GitHub Pages до покупки домена.

Зависимости: Python 3.9+ и всё. Для обложек нужен Pillow (`pip install Pillow`).

## Текущее состояние

- 4 рубрики: Работа и доход, ИИ и инструменты, Дом и быт, Авто и путь
- 19 статей (минимум Дзена в 10 — выполнен с запасом)
- обложки 1200×630 px (требование — не меньше 700 px)
- RSS: полный текст в `content:encoded`, `guid`, `pubDate` в RFC 822, `enclosure`
- `robots.txt` разрешает обход ленты, `sitemap.xml` собирается автоматически
- валидатор: 0 ошибок

## Что нужно сделать вам

1. Купить домен латиницей (IDN Дзен не принимает) и вписать в `site.config.json`.
2. Залить проект на GitHub, включить Pages, подключить домен — шаги в [SETUP.md](SETUP.md).
3. Подтвердить сайт в Яндекс.Вебмастере, отправить `sitemap.xml`.
4. Создать канал в Дзене, набрать 10 подписчиков, подключить RSS.
5. Создать Telegram-бота (5 минут) — инструкция в `SETUP.md`, шаг 7.

## Как добавить статью

1. Файл `content/<рубрика>/<slug>.md` с front matter:

```markdown
---
title: Заголовок до 100 знаков
slug: latinica-cherez-defis
date: 2026-11-24T09:00:00+03:00
description: 1–2 предложения для превью и мета-описания
author: Редакция «Понятно про»
tags: тег1, тег2
cover: kartinka.jpg
status: published
---

Текст статьи. Поддерживаются `##`, `###`, списки, цитаты `>`, **жирный**,
*курсив*, ссылки [текст](url) и картинки ![подпись](путь).
```

2. `python scripts/make_cover.py --list` — обложки для новых статей.
3. `python build.py --clean && python scripts/validate.py`
4. `git commit && git push` — деплой сам.

## Правила, которые нельзя нарушать

- Не менять `guid` уже отправленных статей (будут дубликаты в канале).
- Не публиковать рерайт чужих текстов — Дзен отклоняет такие ленты.
- Не включать `ads.enabled`, пока РСЯ не одобрила сайт.
- Лента отдаёт материалы за последние 45 дней (`feed.window_days`) — Дзен не любит повторную отправку старых публикаций.
