# Бриф на редизайн сайта «Понятно про»

## Что это за сайт

Русскоязычный контентный проект: статьи-инструкции по четырём темам — заработок, нейросети, дом/быт, авто/дача.
Сайт — источник для RSS-трансляции в Дзен. Аудитория 30–50 лет, читают с телефона.

Задача: **сделать визуально современнее и приятнее**, не ломая структуру и не добавляя зависимостей.

## Жёсткие ограничения

- Только CSS. Никакого JS, шрифтов с CDN, внешних картинок, иконочных шрифтов.
- Не менять HTML-шаблоны и другие файлы — только свой CSS-файл.
- Работать с существующими классами (перечислены ниже). Новые классы добавлять нельзя, кроме псевдоэлементов и `:is()/:where()`.
- Светлая тема. Контраст текста не ниже WCAG AA.
- Телефон — приоритет. Проверять мысленно на 360 px и 1280 px.
- Никаких `position: fixed` для тяжёлых панелей, мешающих чтению.

## Проблемы текущего дизайна

1. Обложки огромные (16:10 без обрезки), карточка занимает весь экран — на главной видно 1,5 карточки.
2. На обложке нарисован тот же заголовок, что и под ней — визуальное дублирование. Нужно сделать обложку компактной и второстепенной.
3. Нет сетки: одна колонка на десктопе при пустом пространстве по бокам.
4. Типографика плоская: всё одного веса, нет иерархии.
5. Шапка не закреплена, при прокрутке длинной статьи теряется навигация.
6. Сухие карточки без акцентов, не чувствуется «издание».

## Что хочется получить

- Карточки компактные: обложка с `aspect-ratio` и `object-fit: cover` (например 16/9), сетка 2 колонки от ~760 px, 1 колонка на телефоне.
- Читаемая типографика: заголовок карточки 19–22 px, текст 17–18 px, `line-height` 1.6–1.7.
- Аккуратная шапка: можно `position: sticky` с полупрозрачным фоном и `backdrop-filter`, но с аккуратной высотой.
- Рубрика как маленький цветной «чип» над заголовком.
- Статья: ширина текста ≤ 68ch, крупный `h1`, аккуратные `h2`, списки с воздухом, цитата с акцентной полосой, подпись под картинкой приглушённая.
- Блок «Читайте также» — отдельной карточкой/панелью, не сливаться с текстом.
- Подвал спокойный, мелкий.
- Можно лёгкие тени, скругления 10–14 px, тонкие границы. Без градиентных «попугаев».

## Файл результата

Записать CSS целиком в указанный файл (см. задание). В начале файла — комментарий на 3–5 строк: идея дизайна и что изменено.
Файл должен быть самодостаточным: открыть страницу с этим CSS вместо текущего — и всё выглядит цельно.
