## Как заливать

1. Студия → **Создать** → **Статья**.
2. Заголовок — первая строка md-файла (без #).
3. Тело — блок «Текст для вставки в редактор». Строки, которые должны стать подзаголовками, выделите и примените стиль «Заголовок».
4. Обложка — файл из covers/.
5. В конце статьи вставьте комикс из comics/ как обычную картинку — он читается в ленте и хорошо останавливает прокрутку.
6. Теги — из строки «Теги» в файле.
7. Поле «О чём статья» — строка «Подзаголовок».

## Что внутри комиксов

Три панели: номер, короткий шаг и пояснение. Собраны из подзаголовков статьи, поэтому комикс — это сжатый пересказ материала, а не украшение. Цвет панели соответствует рубрике: синий — работа, фиолетовый — ИИ, зелёный — дом, оранжевый — авто.
